# Tara Jewellery Website

Hero section + Admin panel for managing background photos & videos.

## Quick Start

```bash
pip install -r requirements.txt
python app.py
```

Open: http://localhost:5000

Admin: http://localhost:5000/admin  
Default password: `admin123`

## Features (this version)

- Full-screen hero with photo / video slideshow
- Navigation: Home · Products · Carriers · Testimonials · FAQs · Contact
- Hero text editable from admin
- Upload multiple images or videos as background slides
- Show / Hide / Delete media from admin
- Mobile responsive
- Gold accent buttons matching luxury jewellery feel
